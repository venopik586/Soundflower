## What Is Soundflower?

Soundflower is a free, open-source audio extension for macOS that enables applications to pass audio to one another. In simple terms, it creates virtual audio devices that allow internal sound to be redirected between different programs.

Normally, macOS sends audio output directly to physical devices such as:

* Built-in speakers
* Headphones
* External speakers
* Audio interfaces

Soundflower changes this behavior by introducing virtual audio channels. Instead of sending sound to your speakers, applications can output audio into Soundflower, where other applications can receive and process it.

This capability unlocks numerous possibilities that aren't available through standard macOS audio settings.

## How Does Soundflower Work?

To understand Soundflower, imagine it as a virtual cable inside your Mac.

Normally, audio travels like this:

Application → Speakers

With Soundflower, the path becomes:

Application → Soundflower → Another Application

For example:

Safari → Soundflower → OBS Studio

This means music playing in Safari can be captured directly by OBS without using microphones or external hardware.

Soundflower typically creates two virtual devices:

### Soundflower (2ch)

A two-channel stereo device suitable for most users.

Common uses include:

* Recording desktop audio
* Streaming system sound
* Capturing browser audio

### Soundflower (64ch)

A sixty-four-channel device intended for advanced audio production environments.

Professional users can route numerous audio sources simultaneously using compatible software.
